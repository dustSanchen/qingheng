# 13 · Claude 系审美：可执行清单（给非 Claude 模型用）

> 来源：`D:\AI\codex\Anthropic-Claude_设计语言深度调研报告.md`（含 A/B/C 来源分级）。
> 本文只做一件事：把那份报告的结论压成**动手前/交付前能逐条对照**的规则。
> 适用于轻衡（paper / ledger 双皮肤）。

## 0. 总纲：学秩序，不学体温

- 学：**色阶分层、发丝线、单一强调、字号四层、间距节拍、动效两档、焦点可见**。
- 不学：橙 clay 强调（健康类产品绿色语义更强）、正文衬线（中文小字可读性下降）。
- 警惕：奶油底 + 衬线标题已是「AI 默认制服」，**区分度必须来自信息结构，不是配色**。

## 1. 八条原则 → 落到本仓库

| # | 原则 | 本仓库落点 | 禁止 |
|---|---|---|---|
| 1 | 色阶替代阴影 | 用 `--surface` / `--surface-soft` / `--paper` 三档近色分区块 | 给静态卡片加 `box-shadow` 造层级 |
| 2 | 发丝线用**墨色透明**，不用灰 | 新代码统一 `color-mix(in srgb, var(--ink) 10%, transparent)` | 写死 `#e6dfd8` 一类灰线；灰线与暖底冷暖冲突 |
| 3 | 一个强调色，像标点 | 每屏最多一次强调；主按钮 + 当前态 | 强调色铺满按钮/图标组；小字用强调色（对比度不够） |
| 4 | 字体分三工 | `--font-display` 衬线=标题；无衬线=UI；`font-variant-numeric: tabular-nums`=数字 | 表格/数值用比例数字（列不对齐） |
| 5 | 字号 4–6 级封顶 | 22 / 15.5 / 13.5 / 11 四级，行高固定阶梯 | 临时插入 17px、18px 这类孤例 |
| 6 | 间距 4 基、8/32 主拍 | 4 的倍数；区块间距用流式（clamp/间距变量） | 到处写死 64 / 96 |
| 7 | 动效两档 | 交互 0.2s；揭示 0.8s（工具界面可不用揭示） | 每次操作都跑入场动画；漏 `prefers-reduced-motion` |
| 8 | 焦点环是设计的一部分 | 2px 强调色 + 2px 偏移，`focus-visible` | 依赖浏览器默认焦点样式 |

## 2. 双皮肤约束

- 账本专属规则必须收在 `[data-skin="ledger"]` 或用账本 token；**改动不得回写纸感**。
- 线宽问题先诊断来源：**宽度 / 颜色 / 叠加（描边+阴影+伪元素）**，三者归因不同、改法不同。
  1x 屏幕上 1px 已经是物理最小，看起来「粗」通常是**颜色太重**或**两层线叠在一起**。
- 账本皮肤允许更强的结构线（表格感），但要靠**透明度**调轻重，不靠加宽。

## 3. 反模式（照抄 Claude 风最容易踩的八条）

1. 强调色铺满按钮与图标 → 营销页气质；
2. 纯白 `#fff` 做底 → 失去暖意，与奶油色不咬合；
3. 灰色边框替代墨色透明线 → 冷暖冲突；
4. 只给标题配衬线、正文全无衬线，却仍宣称「Claude 风」→ 只学一半；
5. 静态卡片加阴影 → 与色阶分层打架；
6. 引入第二个饱和色 → 强调色失效；
7. 工具界面套 0.8s 入场动画 → 每次操作都在等「渗墨」；
8. 把具体字体名写死进规范 → 字体一换规范就过期。

## 4. 交付前十条自检

- [ ] 新加的颜色是否都来自 token，没有新增 hex？
- [ ] 新加的线是不是墨色透明，而不是灰？
- [ ] 这一屏的强调色是否 ≤1 次？
- [ ] 数字列是否 `tabular-nums`、右对齐/小数点对齐？
- [ ] 字号是否只用了既有四级，没有孤例？
- [ ] 间距是否都是 4 的倍数？
- [ ] 账本改动是否全部在 `[data-skin="ledger"]` 内？纸感截图是否逐像素未变？
- [ ] 是否有任何静态元素靠 `box-shadow` 造层级？
- [ ] 焦点态在深/浅两套皮肤下是否都可见（≥3:1）？
- [ ] 是否漏了 `prefers-reduced-motion`？

## 5. 一句话记忆

> **用三档近色分区块，用 10% 墨发丝线分边界，一屏一次强调，数字等宽，动效两档，焦点自己画。**

## 6. 边界

- 本清单是「看起来对」的方法论，不替代对具体信息的判断：Claude 系擅长「看起来对」，不擅长「对你对」。
- 不搬 Anthropic 商标资产（颜色/字体/比例/logo），不做暗示背书的表述。

## 7. 自动化：别让清单只活在文档里

`node tools/aesthetic-audit.mjs` 把上面能机械判定的条目变成脚本（只报告，不改文件）：

| 规则 | 判定方式 |
|---|---|
| 色值全部来自 token | 统计 `:root` 之外的十六进制字面量 |
| 发丝线用墨色透明 | 找 `border: 1px solid` 后跟灰系色值 |
| 静态卡片不加阴影 | 找 `.card` 规则里的 `box-shadow` |
| 字号阶梯封顶 | 统计出现的 `font-size` 种类数 |
| 数字等宽 / 焦点环 / 动效降级 / 账本作用域 | 关键字存在性 |
