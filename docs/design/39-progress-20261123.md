**已知坑（避免复访）**
- `app/src/fragments/*.fragment.js` 不能单独 `node --check`（IIFE 收尾在 80-boot），只检查 assemble 后的 `app.js`。
- `adb shell input keyevent 4`（BACK）会弹「退出轻衡？」，关输入法用 `keyevent 111`。
- 脚本改源码时替换串里的 `$$` 会被 `String.replace` 吃掉（写成 `$(`），一律用函数式替换。
- 测试助手 `grab(start, endMarkers)` 的第二个参数是**数组**，传字符串会切出 2 个字符。
