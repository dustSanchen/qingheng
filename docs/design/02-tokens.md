## 2. 硬编码归并规则

总量以 CSV 为准：**209 处 / 176 个不同值**（`00-brief.md` 写「约 190」，口径不同）。

| 判定顺序 | 条件 | 去向 |
|---|---|---|
| 1 | 落在 G10（冷色图表辅助） | **保留**（见 §3） |
| 2 | 同色相、明度差肉眼不可辨（ΔL ≤ 3） | 并入该组主 token |
| 3 | 带 alpha 且用于 `box-shadow` | 改写为 `rgb(var(--shadow-rgb)/α)`，归 `--elev-*` |
| 4 | 带 alpha 且用于遮罩 | `--overlay` |
| 5 | `#fff` 用在主色按钮上 | `--on-accent`，不再借 `--surface` |
| 6 | 一个值只出现 1 次且找不到邻近 token | 标「待人工」，**不强并** |

归并后新增颜色 token（6 个，已计入 41）：

| token | 吸收 | 出现 / 不同值 |
|---|---|---|
| `--accent-soft` | G02 浅绿底 | 61 / 49 |
| `--accent-line` | G03 描边 | 15 / 14 |
| `--accent-deep` | G04 中的深色文字部分 | 12 / 10（阴影部分归 `--shadow-rgb`） |
| `--on-accent` | G08 的 `#fff` ×3 | 3 |
| `--overlay` | G09 的遮罩部分 | 约 3（`rgba(20,20,19,.5)` 等） |
| `--ink-soft` | 次要文字：G01 的 7 个灰绿 + G08 的 `#67766c` | 8 / 8 |

`--ink-soft` 与 `--muted` 的分工：`--ink-soft` 是带绿调的次要文字（状态标签、行内标签，审计 #9），目标改为 `#506053`（见 §0），两皮肤与 `--muted` 的 ΔL\* 均 ≥6。

G01、G05~G08 并入**既有** token（`--accent`、`--warn`、`--danger`、`--paper/--surface`、`--ink/--muted/--line`）。
可归并上限 **201 处（G01~G09）**，其中判定 6 的「待人工」项会从中剔除；G07 的 18 种暖白、G02 的 49 种浅绿是重点。
