# 阶段 3 任务卡 · 组件规范

前置：`00-brief.md`（硬约束）、`01-audit.md`（11 条）、`02-tokens.md`（41 个 token）、`02-mapping.csv`（176 行归类）。

## 交付物

九个组件，每个都要「规范 + CSS diff + 何时用」，纸感与账本各一套取值：

| 组 | 组件 | 输出文件 |
|---|---|---|
| A | 卡片、列表行、分段控件 | `03-components-a.md` |
| B | 表单控件、按钮（主/次/幽灵）、底部弹层 | `03-components-b.md` |
| C | 等待态、空状态（无数据 / 无权限 / 加载失败） | `03-components-c.md` |

### 每个组件写四段

1. **何时用** —— 一句话，给判断依据而不是给定义。例：「同一屏超过 3 张卡片就用列表行」。
2. **token 取值** —— 表格：属性 | 纸感 | 账本。只引用 `02-tokens.md` 里已登记的 token，缺什么就补登记。
3. **CSS diff** —— 改前/改后，只给变动的行，不贴整段选择器。
4. **可访问性** —— 触达尺寸、对比度、焦点态；不达标就写「未达标 + 原因」。

## 约束

- 不引入依赖、不用框架、不加构建步骤。
- 不动品牌色 `--accent`。
- 正文对比度 ≥4.5:1；交互控件边界与焦点指示 ≥3:1。**达不到就换色值，不要降低标准后标注了事。**
- 差异只在纸感/账本两列体现，不要在组件内部再造第三套变量。

## 本轮必须先解决的三处（阶段 2 遗留）

1. **token 现值的口径**：L3–L47 的 `--paper/--ink/--muted/--line` 被 L50 的 `:root` 覆盖，
   表里引用的「现值」与实际生效值不符。统一以**实际生效值**为准，被覆盖的标为「未生效/历史」。
2. **`var(--card,#fff)` 的 7 处回退值永远生效**（`--card` 全文件未定义），
   结果是纯白而不是暖白。统一到 `--surface`，并核对账本下是否仍成立。
3. **`--ink-soft` 在账本下与 `--muted` 几乎同深**（ΔL* ≈ 1）。
   要么调深到与 `--muted` 拉开 ≥6 ΔL*，要么在账本下不启用该 token。
