## 给模型的判断要点

1. **G02 有 49 个不同值却只出现 61 次**——平均每个值只用 1.2 次，说明是手工调出来的近似色，是最该收敛的一组。
2. **G07 的暖白有 18 个不同值**，纸感皮肤的「纸」其实是十几张不同的纸，需要一个统一的 `--paper` 与 `--surface`。
3. **G04 全部带 alpha 通道**（`#293c3280` 这类），说明它同时承担「深色文字」和「阴影」两种角色，必须拆成两个 token。
4. **G09 是 rgba 而非 hex**，主要是投影与遮罩，应独立成阴影令牌，不要混进颜色层。
5. **G10 只有 8 处**，是图表辅助色，建议保留硬编码并在规范里注明「不参与主题」。
