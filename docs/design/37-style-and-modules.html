美术风格与四模块修改方案

这份稿子做两件事：把身体 / 习惯这一块的美术口径落成可对照的实物（不是形容词）， 再把用户四模块清单里的每一条落成在原版之上的增量改法。 所有组件都按 1.5.25 装机版的真实值排：颜色、字阶、间距、圆角、动效都是 styles.css 里的 token。

二 · 两套口径与一条共用红线

rules

今天页（v2）

  • 卡片无 1px 边框，改用弥散阴影 + 底色阶梯。
  • 渐变只给三处：能量环、宏量进度条、行动罗盘。
  • 磨砂只给 Sheet / 浮层，卡片与正文禁用。
  • 按压 scale(.98)，胶囊换文案 180ms 上浮淡入。

记录 · 身体（原规范）

  • 静态卡不加阴影，靠发丝线与底色阶梯分区。
  • 数字 20–22px 半粗、等宽；单位小一号、次要色。
  • 指标块用左侧 3px 色条 + 6% 色底区分（不是靠图标）。
  • 一屏可以有多个重点：卡各自有标题与唯一动作，不强行只留一个。

共用红线

  • 一个表单只有一个主按钮：习惯卡保存、训练保存、身体保存各一个 primary，其余降为次按钮或文字链。
  • 颜色只走 token：新增色用 color-mix 派生，不写新的 rgba / hex 字面量。
  • 不引依赖：动作、动效、图标都在本仓库内解决。
  • 改完必须 assemble-app ＋ test-all 全绿，再装机截图。

七 · 验收

acceptance

每一轮都要过的

  • node tools/test-all.mjs 全绿（基线 112，改口径时同步翻转断言）。
  • node tools/aesthetic-audit.mjs 无阻塞项（无灰线、无卡阴影、无越界色）。
  • node tools/entry-budget-audit.mjs 记身体/记训练同动作 ≤2 处。
  • 装机截图与 build/v25-* 基线逐项对照，差异要能一句话说清是「加」还是「换」。

这一版的人眼判据

  • 三张刻度卡看起来是同一族：色条、圆钮、轨道、胶囊的位置都在同一行高上。
  • 看不出「新做了一套表单」——大数字仍是卡里最大的一处。
  • 习惯卡底部只剩两件事，眼睛不用在五个动作里挑。
  • 睡眠卡出现后，这一区读起来是「日常三项」，不是「两项加一个补丁」。

偏离登记：warm-paper 卡要求圆角 ≤4px、禁止阴影；本稿按品牌保留 8/12 圆角与「今天页主卡一条 6% 弥散阴影」，理由是轻衡已有两套皮肤与四模块的卡片半径，改卡不改品牌。
