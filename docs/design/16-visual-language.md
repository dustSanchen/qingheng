# 16 · 图像语言 / 趋势图 / 主行动（规格，2026-10-29）

本文件是规格而非实现记录：三项都需要动渲染层，按单轮单主题分离。

## 一、图像语言：三个符号，一套参数

轻衡现在没有自己的图形。全 App 的“图形”只有两类：通用线性图标（21 个 SVG）和状态点。
要有一点点识别度，只需三个符号，且必须共用同一套几何参数。

| 符号 | 语义 | 出现位置 |
|---|---|---|
| 叶（leaf） | 记录 / 生长 / 一餐 | 空态、记录成功、卡片角标 |
| 天平（balance） | 目标 / 权衡 / 区间 | 今日能量、目标行、体检卡 |
| 环（ring） | 周期 / 连续 / 进度 | 趋势、连续记录、周汇总 |

几何硬参数（三符号共用，违反即不算同一套）：

- 画布 24×24，安全边距 3px（内容不超出 3–21）
- 线宽 1.5px，圆头（stroke-linecap: round）圆角连接（linejoin: round）
- 只用描边，不用填充（唯一例外：完成态的叶，可填 var(--accent) 的 12% 透明度）
- 单色：默认 currentColor；不出现第二种颜色
- 最小使用尺寸 16px，最大 96px；缩放靠 viewBox，不重绘

三态用法：

- 空态：符号 40px + 一句说明 + 一个动作（现在的 sparkle 换成对应符号）
- 加载：环符号 20px + 1.2s 匀速旋转（尊重 prefers-reduced-motion 时静止）
- 完成：叶符号 24px + `--ok` 色 + 不加动效

## 二、趋势图：补三件事

现状：折线 + 周均值虚线 + 5 条网格 + nice ticks，无交互、无空态骨架、无区间。

1. **点按取数**：每个数据点 44dp 透明热区；点按后在点上方显示“日期 / 体重 / 变化”，3s 后自动收起。
2. **目标区间带**：体重目标若存在，画一条 12% 透明度的水平带（上限/下限），比两条虚线更易读。
3. **空态骨架**：无数据时显示环符号 + “记录第一笔体重，趋势从这里开始”，不画空坐标轴。

约束：不引入图表库；hitbox 用 SVG `<circle r=22>` 透明填充；键盘可达（Tab 聚焦、方向键在点间移动）。

## 三、主行动：sticky 底栏

问题：记录页、问答页的主按钮要滚动才可见（此前还被“快速记录”挤出屏）。

规格：

- 底栏 `.action-bar`：固定在 `.bottom-nav` 之上（`bottom: calc(var(--tabbar-h) + env(safe-area-inset-bottom))`），高度 64px，纸底 + 顶部 1px var(--line)。
- 主按钮唯一：底栏内只放一个 `.button.primary`；次要动作降级为文本按钮放在卡内。
- DOM 顺序：主按钮必须写在内容流**最后**，且任何新控件不得 `insertBefore` 到主按钮之前（1.1.64 的“点不到记录一餐”就是这么来的）。
- 滚动留白：`.view` 已有 84px 底部留白，底栏出现时改为 `calc(64px + var(--tabbar-h) + 16px)`。
- 收起规则：内容不足一屏时不显示底栏，避免空页面挂着一个按钮。
