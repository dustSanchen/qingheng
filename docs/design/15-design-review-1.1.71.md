# 轻衡 App 设计审查与优化清单（v1.1.71 · 2026-10-29）

审查对象：真机 `3cba2bdc`，`cn.qingheng.health` 1.1.71（versionCode 171），1156×2510 / density 2.752。
方法：`uiautomator dump` 抽节点树 + `screencap` 截图 + `dumpsys gfxinfo` 帧统计 + 像素采样算对比度。
本轮补齐了上次未验证的三项：问答页、皮肤切换、性能；顺带做了无障碍标注扫描。

## 一、验证结果（先给数）

| 项 | 结果 | 判定 |
|---|---|---|
| 冷启动 | 267–308ms（两次 force-stop 后启动） | 优 |
| 滚动帧率 | 456 帧，Janky 2 帧（0.44%），p50 5ms / p95 7ms / p99 12ms，Missed Vsync 0 | 优 |
| 对比度 | 正文 6.81–10.72:1，次要文字 4.97:1，chip 文字 4.97:1 | 达标 AA |
| 可点元素 | 16 个中 5 个无 text/content-desc（4 个为全宽卡片容器，子节点有文字可合并朗读；1 个是 0 高位被裁切） | 基本达标 |
| 皮肤状态 | 当前 = 纸感（非「自动」） | 与文案不符 |
| 账本皮肤 | 近白底 + 无衬线，**是浅色不是暗色** | 与「夜间模式」文案矛盾 |

## 二、必须修（功能与承诺不一致）

1. **「训练」与「身体」两个 tab 内容完全相同**
   - 证据：两个选中态各 dump 一次，首屏文本序列逐字一致（训练计划 / 每周训练 / 3 次 …）。
   - 改法：给「身体」独立内容（体重/围度/体脂），或暂不出 tab；不要留一个空壳。

2. **「账本」不是夜间模式**
   - 我的页文案写「系统深色时全程账本（夜间模式）」，但账本实测是 `#F6F7F5` 近白底 + 深灰字。
   - 影响：夜里切过去更刺眼，文案承诺无法兑现。
   - 改法：要么补一套真暗色（画布 #12130F 级、墨色反向、语义色降饱和），要么把文案改成「账本：数据优先的浅色」并去掉「夜间模式」。

3. **皮肤当前值与「默认自动」不符**
   - 我的页副标题显示 `paper`，皮肤选项勾选在「纸感」，而说明文字写「默认「自动」」。
   - 改法：统一口径——要么默认真给「自动」，要么改文案；副标题显示当前值（纸感/账本/自动）而不是 `paper` 内部名。

## 三、该修（认知负担）

4. **授权勾选重复**：首页一张卡里两个勾（用 AI 建议 / 同意外发健康记录）；问答页又是两个勾（外发问题+照片+健康数据 / 联网检索）。
   - 改法：每处收敛成一个主开关，勾上后展开明细；联网检索作为二级选项折叠。

5. **问答页「分析日期」出现两次**：先一个日期选择器，下一行又写「分析日期：2026-10-29 · 已保存 0 条餐食」。
   - 改法：选择器右侧直接挂「0 条餐食」角标，删掉重复行。

6. **「清空记录」的位置与样式偏轻**（更正：二次确认**已经有**——代码里是 `askConfirm('确定清空本机问答记录吗？此操作无法撤销。', {danger:true})`，我最初只看了静态截图，判断错了）。
   - 剩余问题只是位置：它和「只看收藏」筛选并排，视觉权重相同。
   - 改法：移到列表右上「⋯」菜单，或在文案前加图标区分；确认框不用改。

## 四、视觉与排版

7. **卡中卡**：记录页「训练日志」卡片内再套一层 20px 圆角容器承载输入项，双层描边 + 双层底色。
   - 改法：输入区降级为无底色分组（1px 线或 8px 间距），全页只保留一层 card。

8. **中文拦腰断行**：`哑铃按单|只记`、`65|kg`、`从了解自己开|始。`（孤字成行）。
   - 改法：数字+单位用不换行空格（U+00A0）；空状态文案压到 ≤22 字；对中文标题手动断行或用 balanced 换行。

9. **chips 换行参差**：「器械」「单次时长」两组末行只剩 1 项，宽度随文字自适应。
   - 改法：改等宽网格（每行 3 或 4 等分），末行留空不拉伸。

10. **趋势图刻度不圆整**：63.3 / 63.9 / 64.4 / 65 / 65.6 由数据极值插值；无 x 轴日期。
    - 改法：nice ticks（0.5 或 1 的整数步长，含上下界），补首尾日期；点按显示当日值。

## 五、可用性

11. **触控目标不足 48dp**：趋势页「减载」29×25dp、记录页表单行 27dp、皮肤选项 42dp。
    - 改法：图标按钮加不可见热区到 48dp；表单行 ≥56dp；chip ≥44dp。

12. **首屏主行动被导航遮挡**：问答页「拍照提问 / 从相册选」初始只露上半，滚动后可见；记录页底部保存同理。
    - 改法：主 CTA 做 sticky 底栏（位于 nav 之上），或压缩首屏内容，保证主行动完整可见。

## 六、做得好的地方（保留）

- 四个 tab 各有一句人话标题：照顾自己，从今天开始 / 让日常，有迹可循 / 有疑问，问一句 / 把目光，放长一点 / 你的节奏，你来定义。
- 纸感 + 衬线标题 + 苔绿强调色，气质自洽，不是模板风。
- 性能优秀（启动 267ms、jank 0.44%），说明动效与列表都没过度渲染。
- 「外部 AI · 按 token 计费」「联网检索只发问题文字」这类披露很诚实，这点比多数健康 App 好。

## 七、建议实施顺序

1. 修 tab 同内容 + 皮肤文案两处（都是「说一套做一套」，最伤信任）。
2. 合并授权勾选、删重复日期行、给「清空记录」加保护。
3. 去卡中卡、修断行、chips 改网格。
4. 趋势刻度与 sticky CTA。
5. 若要真夜间模式，单独做一套暗色令牌（画布/墨色/语义色/图表色），不要在账本上改。
## 八、静态审计交叉结果（`node tools/aesthetic-audit.mjs`）

仓库自带的审美审计跑出来 6 个 WARN，和我真机看到的能对上：

| 审计项 | 结果 | 与真机发现的关系 |
|---|---|---|
| 色值全部来自 token | WARN：93 处 token 外硬编码 | 解释了纸感/账本之间那些「说不清为什么不一样」的浅色差异 |
| 静态卡片不加阴影 | WARN：4 处 `.card` 带 box-shadow | 与「卡中卡」叠加，形成三层视觉重量 |
| 字号阶梯封顶 | WARN：18 种字号（12.5–32） | 对应条款过密、层级感弱 |
| 发丝线用墨色透明 | WARN：3 处疑似灰线 | 与截图中描边偏灰度一致 |
| 强调色收敛 | WARN：11 处 accent token 声明 | 主按钮/选中态绿色深浅不一 |
| tabular-nums / focus-visible / reduced-motion / 账本作用域 | PASS | 动效与无障碍底子是好的，这一点真机也验证了 |

> 结论：静态审计抓「令牌纪律」，真机抓「交互与内容」；两边都不重叠，建议每轮都跑一遍。
