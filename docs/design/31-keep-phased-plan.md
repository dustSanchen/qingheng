## 1. 目标

按 Keep 的有效原则减少决策，而不是复制 Keep 的课程、社区或会员体系：

1. 打开今天页就知道下一步做什么，并且只有一个主行动。
2. 建议能进入既有记录动作；AI 不得直接写健康记录。
3. 偏好可见、可改、可携带；旧数据迁移不丢。
4. 周回看只依据真实记录，数据不足不硬评。
5. 核心记录、目标计算、训练执行离线可用。

### 阶段验收要点

- M1：明确休息不出现“补训练”；未记录不等于没做；不训练用户不生成训练催促。
- M2：旧字符串建议仍可用；非法/越界 `actionItems` 被丢弃；按钮只打开表单。
- M3：体重只比实测周均值；样本不足不伪造对比；训练关闭不出现训练行。
- P2：AI/权限可跳过；保存餐食按原记录 id 更新，不新增副本；键盘遮挡时能回到编辑控件。
- P1-C：草稿卡只出现于明确的进食描述；问句/计划/训练/体重句不误识别；点“去确认餐食”只填入表单。
